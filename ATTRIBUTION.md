# Protocol research attribution

MacroPilot's `1189:8890` compact-protocol adapter was informed by the public
reverse-engineering discussion, ["HID macropad key programming doesn't give
expected results"](https://stackoverflow.com/questions/75870303/hid-macropad-key-programming-doesnt-give-expected-results), on Stack Overflow.

The source material is credited to its author and is available under the
[CC BY-SA 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).
MacroPilot's mapper is an independently written implementation of the device
protocol; no vendor binary or source code is included in this repository.
