# CH57x 0x8890 hardware adapter

The first MacroPilot reference device is the generic wired six-key, one-knob
macropad reporting USB vendor ID `0x1189` and product ID `0x8890`.

MacroPilot deliberately separates two concerns:

1. The hardware receives neutral keyboard events (`F13` through `F21`).
2. A host profile assigns meaning to those events for a particular workflow.

This lets the same physical configuration work with AI tools, video editors,
streaming apps, accessibility tools, and ordinary desktop automation.

`ch57x-keyboard-tool` is an independent open-source utility that can validate
and upload the YAML mapping. Uploading is an explicit user action because it
changes the macropad's onboard memory.

## Reference layout

```text
knob | Summon | Voice   | Context
     | Stop   | Send    | New
```

- Turn: scroll up/down
- Press: select next profile
- Send and New are marked as confirmation-requiring actions in the host profile.
